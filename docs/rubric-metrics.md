## 定义

- 单位：一对（图像，标注记录），和 PQ 的统计单位相同。预测是 C2 嵌套选择保留的候选，种子 0、1、2 各算一次；表中数字为种子 0，末尾另列三个种子的差异。
- Dice：该记录所有实例的前景并集，对比保留预测的前景并集。
- IoU：TP 的匹配 IoU；每个 GT 的最佳 IoU（没有碰到预测记 0）；每个预测的最佳 IoU。
- 关系：当 |g∩p|/|g| ≥ c 或 |g∩p|/|p| ≥ c 时，g 和 p 之间有一条边；c 取“任意重叠”、0.1、0.5。“一对多”指一个 GT 连到 ≥2 个预测，“多对一”指一个预测连到 ≥2 个 GT。
- 有一条记录（20160810234034Lh，第 3 条）的两个 GT 几乎重合，同一个预测和它们的 IoU 都超过 0.5，按官方 PQ 算 2 个 TP。所以两个方案的 TP + FP 都比预测数多 1。
- 这是 3 折外折预测（707 张物理图），不是测试集结果。S4V8 是 14 个分支里选出来的，它和 E059 的差异不能当作提升。
